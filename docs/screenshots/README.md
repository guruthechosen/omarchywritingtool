# Screenshot notes

`proofread.png` and `translate.png` show the unmodified `bin/tot-review.py`
GTK4 interface, using the Adwaita dark theme. Input and output were prepared
for demonstration; these are not live provider responses or quality benchmarks.
No personal clipboard contents, configuration, or credentials were used.

Captured on 2026-10-22 using GTK's Broadway backend on loopback, with an isolated
review window. This avoids capturing the user's desktop or other applications.
No Copy button was pressed and no external provider was called.

The root `preview.png` is a presentation of the proofreading screenshot with
explanatory text. Its layout source is `../preview.html`; open it with a
1280 × 800 browser viewport to reproduce the composition. It is a promotional
overview, not a screenshot of an Omarchy desktop. The separate screenshots
above show the application itself. Theme and menu-picker appearance vary.
